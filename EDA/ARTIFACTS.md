# EDA artifact manifest

## Published artifacts

The GitHub-published EDA bundle includes:

- Final Quarto source and self-contained HTML report
- All Python scripts required to rebuild the analytical tables and EDA outputs
- Summary CSV and Markdown outputs
- SVG visualizations
- Donor-clustered bootstrap estimates and reproducibility metadata

## Locally generated datasets

The following files are generated under `EDA/derived_data/` and intentionally
excluded from Git:

| File | Approximate size | Generated by |
|---|---:|---|
| `donor_fiscal_year_core.csv` | 59 MB | `build_donor_fiscal_year_core.py` |
| `donor_fiscal_year_features.csv` | 134 MB | `build_donor_fiscal_year_features.py` |
| `eda_eligible_fy2023_2025.csv` | 50 MB | `eda_eligible_fy2023_2025.py` |

`donor_fiscal_year_features.csv` exceeds GitHub's standard 100 MB per-file
limit. Publishing generated donor-level data would also unnecessarily duplicate
information that can be recreated from the synthetic source files.

## Generation order

Run these commands from the repository root:

```bash
python EDA/scripts/build_donor_fiscal_year_core.py
python EDA/scripts/build_donor_fiscal_year_features.py
python EDA/scripts/eda_eligible_fy2023_2025.py
python EDA/scripts/create_initial_eda_visualizations.py
python EDA/scripts/bootstrap_clustered_lift.py
quarto render EDA/pbs_utah_final_eda_report.qmd --to html --embed-resources
```
